America in Numbers — a national statistics site for the United States: population, economy, health, education, environment and all 50 states, with real figures from the World Bank (2015–2024), the U.S. Bureau of Economic Analysis and the U.S. Census Bureau.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
